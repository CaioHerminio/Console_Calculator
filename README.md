# 🧮 Console Calculator

A simple console-based calculator written in C++. This project allows users to perform basic arithmetic operations on two numbers using addition, subtraction, multiplication, and division.

![Console Calculator Banner](banner.png)

## 📌 About the Project

The **Console Calculator** is a beginner C++ project created to practice fundamental programming concepts through a practical application.

The program asks the user to enter two numbers and choose an arithmetic operation: addition (`+`), subtraction (`-`), multiplication (`*`), or division (`/`).

It then uses a `switch` statement to determine the selected operation, perform the calculation, and display the result. If the user enters an unsupported operator, the program displays an invalid operation message.

## ✨ Features

- 🔢 Input the first number
- ➕ Perform addition
- ➖ Perform subtraction
- ✖️ Perform multiplication
- ➗ Perform division
- 🔀 Select arithmetic operations using a `switch` statement
- 🧮 Calculate and display the result
- ⚠️ Display a message for invalid operators

## 🛠️ Technologies

- **Language:** C++
- **Standard Library:** `<iostream>`
- **Interface:** Command-line interface (CLI)
